# Free AI v0.7.2 release candidate

This release candidate carries the Windows/browser-runtime fixes and plugin-directory follow-up validated on the v0.7.2 development line.

## Included fixes and improvements

- Hardened Gemini prompt submission against current composer/send-control variants.
- Added ChatGPT image-only/generated-media capture and kept media scoped to the current reply.
- Restored persisted chat provider selection after Browser Bridge reconnects and browser tab-ID changes.
- Hardened nested provider-app routing through current provider menus.
- Reworked the Windows Plugins surface around a directory-first model while keeping public listings separate from real installed/provider/direct-MCP connections.
- Added explicit Public, Workspace, and Personal plugin-directory scopes without pretending workspace/private authorization is available when the provider has not exposed it.
- Expanded Windows visual/interaction and provider-runtime regression coverage.
- Kept Android production-signing, email/session auth, Google Credential Manager, and phone/large-phone/tablet runtime gates in the release matrix.

## Distribution policy

Windows Authenticode remains optional. Android production signing is required. macOS may be published unsigned when Apple signing is intentionally deferred by the release workflow.
